## 🧩 Single-Clip Prompt Formula

Every generated prompt strictly follows this 5-stage micro-scene blueprint inside 1 continuous shot:

* **0:00–0:02:** Macro workbench view inspecting raw materials and micro tools.
* **0:02–0:04:** Rapid precision slicing, carving, cutting, or soldering with fine detail.
* **0:04–0:07:** Tactile assembly, clicking components, and seating moving parts.
* **0:07–0:09:** Revealing and testing the finished, functioning miniature gadget.
* **0:09–0:10:** Seamless camera glide resetting perspective back to the starting workbench state for infinite looping.
